## 提交项目

欢迎提交你的或你知道的浙大同学开源项目，详见 [贡献指南](CONTRIBUTING.md)。

不熟悉 PR 也没关系，直接 [提 Issue](../../issues/new) 留下项目链接即可。

### 用 AI Agent 提交

如果你正在使用 Claude Code、Cursor、Copilot 等 AI 编程工具，可以把下面这段话直接发给它：

> 帮我向 https://github.com/ZJU-AIRA/awesome-zju-opensource 提交一个项目。请先阅读该仓库的 CONTRIBUTING.md 了解格式要求，然后 fork 仓库，在 README.md 的项目列表末尾添加一行，最后提交 PR。项目信息：名称 xxx，链接 xxx，简介 xxx，标签 xxx，作者 xxx。

## 声明

本仓库是社区维护的聚合列表，不代表浙江大学官方立场，不对收录项目进行质量或安全性背书。

如果你的项目被收录但你不希望出现在此列表中，请 [提 Issue](../../issues/new) 或联系维护者，我们会尽快移除。
